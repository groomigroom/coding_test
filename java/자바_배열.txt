자바에서 배열에 요소를 추가하는 방법은 배열의 크기가 고정되어 있어 직접 요소를 늘릴 수 없으므로, 크기가 가변적인 ArrayList를 사용하거나 새로운 배열을 생성해 복사해야 합니다. (만약 배열 안의 모든 숫자의 '합계'를 구하는 의미라면 반복문을 참고하세요.) [1] 
------------------------------
## 1. 요소를 동적으로 추가하고 싶을 때 (ArrayList 사용)
가장 추천하는 방법은 크기가 자동으로 조절되는 ArrayList로 변환하거나 처음부터 사용하는 것입니다. [1, 2] 

import java.util.ArrayList;import java.util.Arrays;import java.util.List;
// 배열을 리스트로 변환 후 추가
Integer[] arr = {1, 2, 3};
List<Integer> list = new ArrayList<>(Arrays.asList(arr));
list.add(4); // 요소 추가
// 다시 배열로 변환
Integer[] newArr = list.toArray(new Integer[0]);

## 2. 기존 배열 크기를 늘려 새 요소 추가하기 (System.arraycopy)
원시 배열(int[] 등)을 유지해야 할 경우, 더 큰 배열을 새로 만들고 기존 값을 복사합니다. [1, 3] 

int[] original = {1, 2, 3};int[] extended = new int[original.length + 1];
// 기존 배열 복사
System.arraycopy(original, 0, extended, 0, original.length);
// 새 요소 추가
extended[extended.length - 1] = 4;

------------------------------
## 3. 배열 안의 모든 요소 값들을 '더하기(합계)'할 때
만약 요소를 추가하는 것이 아니라 배열 안의 숫자들을 모두 더하는 의미라면 for 문이나 Stream을 사용합니다. [4, 5] 

* 향상된 for 문 사용:

int[] numbers = {1, 2, 3, 4, 5};int sum = 0;for (int num : numbers) {
    sum += num;
}
System.out.println(sum); // 15

* Stream API 사용: [4, 6] 

import java.util.Arrays;
int[] numbers = {1, 2, 3, 4, 5};int sum = Arrays.stream(numbers).sum();
System.out.println(sum); // 15

네, 파이썬의 insert, pop, del과 동일한 역할을 하는 자바의 기능들이 있습니다.
자바에서는 파이썬의 리스트처럼 요소를 자유롭게 추가하고 삭제하려면 반드시 ArrayList(또는 List)를 사용해야 합니다.
파이썬의 메서드들과 매칭되는 자바의 ArrayList 사용법을 정리해 드립니다.
------------------------------
## 1. insert(index, value) ➔ 자바: add(index, value)
파이썬처럼 특정 인덱스 위치에 요소를 삽입하고, 뒤에 있는 요소들을 한 칸씩 밀어냅니다.

* 파이썬: list.insert(1, "B")
* 자바: list.add(1, "B");

import java.util.ArrayList;

ArrayList<String> list = new ArrayList<>();
list.add("A");
list.add("C"); // 현재 ["A", "C"]
// 인덱스 1번에 "B" 삽입
list.add(1, "B"); // 결과: ["A", "B", "C"]

## 2. pop(index) ➔ 자바: remove(index)
특정 인덱스의 요소를 삭제하면서, 그 값을 반환(Return)합니다. 인덱스를 지정하지 않고 마지막 요소를 꺼내려면 list.size() - 1을 인덱스로 넘겨주면 됩니다.

* 파이썬: item = list.pop(1) (인덱스로 꺼내기) 또는 item = list.pop() (마지막 요소 꺼내기)
* 자바: String item = list.remove(1);

ArrayList<String> list = new ArrayList<>();
list.add("A"); list.add("B"); list.add("C");
// 1번 인덱스("B")를 꺼내고 삭제
String removedItem = list.remove(1); 

System.out.println(removedItem); // 출력: B
System.out.println(list);        // 출력: [A, C]

## 3. del list[index] 또는 remove(value) ➔ 자바: remove()
파이썬에서 del은 인덱스로 지우고, remove()는 값으로 지웁니다. 자바는 remove() 메서드 하나가 오버로딩(Overloading)되어 있어, 인덱스와 값 둘 다 지울 수 있습니다.

* 인덱스로 지우기 (파이썬 del과 매칭):
* 자바: list.remove(index); (해당 인덱스 요소 삭제)
* 값으로 지우기 (파이썬 remove와 매칭):
* 자바: list.remove(Object value); (처음 발견된 해당 값을 삭제하며, 성공 여부를 true/false로 반환)

ArrayList<String> list = new ArrayList<>();
list.add("Apple"); list.add("Banana"); list.add("Cherry");
// 1. 인덱스로 지우기 (Banana 삭제)
list.remove(1); 
// 2. 값으로 직접 지우기 (Cherry 삭제)
list.remove("Cherry"); 

⚠️ 주의 (int형 리스트를 사용할 때):
ArrayList<Integer>처럼 숫자가 들어있는 리스트에서 list.remove(5)를 하면, 값 5가 아니라 5번 인덱스를 삭제하려고 합니다. 만약 숫자 5를 직접 지우고 싶다면 list.remove(Integer.valueOf(5))와 같이 객체 형태로 감싸서 전달해야 합니다.
------------------------------
## 한눈에 보는 요약 비교표

| 기능 | 파이썬 (Python) | 자바 (Java ArrayList) |
|---|---|---|
| 맨 뒤에 추가 | list.append(x) | list.add(x) |
| 원하는 위치에 삽입 | list.insert(i, x) | list.add(i, x) |
| 인덱스로 삭제 및 반환 | list.pop(i) | list.remove(i) |
| 인덱스로 삭제만 하기 | del list[i] | list.remove(i) |
| 값으로 찾아서 삭제 | list.remove(x) | list.remove(x) 또는 list.remove(Integer.valueOf(x)) |
